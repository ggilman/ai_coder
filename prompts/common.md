# Working in this environment

- The project is mounted at `{workspace}`; that is the working directory. Use paths inside it.
- Read a file before you edit it, and edit with text copied exactly from what you read.
- If an edit fails, re-read the file before trying again; do not retry the same edit blind.
- When you use a tool, emit the actual tool call, then wait for its result before the next step.
- Do not invent APIs, flags or file contents; check the code or run a command instead.
- Keep replies short: say what you changed and why.
